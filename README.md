# Oxide Portfolio

Award-winning brutalist-futuristic personal portfolio website built with React, TypeScript, TailwindCSS, and Framer Motion.

**Built by Oxide — Full-Stack Developer (Rust, TypeScript, React.js)**

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Styling:** TailwindCSS 4 + custom CSS animations
- **Animation:** Framer Motion, @use-gesture/react
- **Build:** Vite 6
- **Deploy:** Vercel

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Scripts

| Command            | Description                       |
| ------------------ | --------------------------------- |
| `pnpm dev`         | Start Vite dev server with HMR    |
| `pnpm build`       | TypeScript check + production build |
| `pnpm preview`     | Preview production build locally  |
| `pnpm lint`        | Lint and auto-fix source files    |
| `pnpm format`      | Auto-format with Prettier         |
| `pnpm type-check`  | TypeScript type checking          |

## Design Philosophy

- **Brutalist-Modern:** Raw edges, visible structure, monospace typography, high contrast
- **Futuristic:** Glitch effects, scanlines, neon accents, animated grids, parallax depth
- **Heavy Animation:** Intentional motion everywhere, GPU-accelerated 60fps, graceful degradation
